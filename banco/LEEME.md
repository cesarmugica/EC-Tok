# Banco de animaciones

Para publicar un banco nuevo sin subir nada a mano:

1. Pon las animaciones nuevas (`.webm` con transparencia) en `banco/nuevos/`.
2. Cambia el número en `banco/siguiente.txt` (el banco que se va a publicar).
3. Haz push: GitHub toma el banco anterior, le agrega lo de `banco/nuevos/` y publica el release `banco-N` con `ectok-banco-N.zip`.

EC-Tok lo encuentra con «Buscar actualización» en el banco de animaciones.
